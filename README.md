# الطرفية العربية الأصلية — Musab / Term

تطبيق طرفية Android أصلي باللغة العربية، مجاني ومفتوح المصدر، لا يتطلب Termux أو ADB أو Wi‑Fi، ولا يستخدم أي API سحابي أو اشتراك. **ليس مجرد نافذة تعرض نص الأوامر**: يبدأ جلسات Android Shell عبر محرّك PTY مكتوب بلغة C باستخدام NDK، ويستقبل تدفق الطرفية ويتعامل مع لوحة المفاتيح وأوامر التحكم.

## الميزات المنفذة

- واجهة عربية مع مفاتيح هروب، جدولة، الأسهم، Ctrl+C وCtrl+D وCtrl+Z.
- محرّك جلسات PTY أصلي مدمج، مع جلسات متعددة حتى ست جلسات وتبديل بينها؛ وضع اختياري لإرسال نص خام إلى البرامج التفاعلية.
- أوامر عربية محلية: «مساعدة»، «الملفات»، «أين أنا»، «الهاتف»، «البطارية»، «الرام»، «التخزين»، «أنشئ ملف»، «أنشئ مجلد»، «اذهب إلى»، «اقرأ»، «احذف ملف» (بتأكيد) وغيرها.
- استقبال UTF‑8 وكتابة نص عربي في الشل، وعرض ANSI/VT: محرك شاشة، حركة المؤشر، تعديل السطر، مناطق التمرير، الشاشة البديلة، 16 و256 لونًا وألوان RGB وتقرير موضع المؤشر.
- استيراد ملف واحد يختاره المستخدم عبر Android Storage Access Framework، ونسخ محتوى الشاشة.
- تشغيل أدوات Android النظام المتاحة لحساب التطبيق عبر /system/bin/sh.
- محاولة صلاحيات Root اختيارية فقط عندما يقدم النظام su ويمنح الجهاز الإذن.
- لا يتطلب إذن INTERNET في ملف Manifest؛ ولا يعتمد وقت التشغيل على خادم أو تطبيق آخر.

## الحدود التقنية الفعلية

- **لا تستطيع التطبيقات غير المروّتة تجاوز عزل Android Sandbox أو SELinux أو الوصول إلى ملفات بقية التطبيقات.** لا توجد طريقة مشروعة لتحويل تطبيق عادي إلى Root تلقائيًا.
- يعتمد بحكم الضرورة على Android OS وLinux kernel وsystem shell وAndroid SDK/NDK. لا توجد حزم Python أو Node أو Git مرفقة، وقد لا تكون متاحة في صدفة النظام الافتراضية.
- محرك ANSI محلي قيد الاختبار، ولم يتم إثبات التوافق الكامل مع جميع تطبيقات VT100/xterm أو البرامج مثل vim/tmux؛ العربية والرموز الثنائية العرض قد تختلف باختلاف خط النظام.
- لا يمكن ترجمة المخرجات التي تنتجها برامج طرف ثالث تلقائيًا دون مترجم إضافي أو تعديل تلك البرامج.
- التطبيق الحالي لا يقدم هوية root على جهاز غير مروّت، ولا يقدم أوامر نظام تتطلب أذونات غير ممنوحة.
- لا يعتبر APK مُختبرًا على جهاز فعلي قبل إجراء تجربة تشغيل ميدانية.

## البناء

من تبويب **Actions** في هذا المستودع، افتح **بناء الطرفية العربية APK** وشغّل workflow إن لزم. عند نجاحه، نزّل ArabicTerminal-debug-APK من Artifacts واستخرج app-debug.apk وثبّته على جهازك. هذا ملف Debug للتجربة، وليس إصدارًا موقعًا بتوقيع إنتاج مستمر.

للبناء محليًا تحتاج JDK 17، Gradle 8.13، Android SDK 36 وNDK 27.2.12479018 وCMake 3.22.1. نفّذ:

    gradle assembleDebug

لاختبار الطبقة المستقلة من Java:

    mkdir -p tests/out
    javac -encoding UTF-8 -d tests/out app/src/main/java/io/musab/arabicterminal/{ArabicCommandRouter,TerminalScreen}.java tests/Checks.java
    java -cp tests/out Checks

## خارطة الطريق

1. تدقيق الأداء والتوافق مع برامج TUI الشائعة على جهاز Android حقيقي.
2. تحسين عرض اتجاه النص المختلط، تشكيل العربية والخلايا واسعة العرض.
3. جلسات أكثر استمرارية عبر Android foreground service والاحتفاظ بالحالة وفق سياسات البطارية.
4. توفير أدوات Linux اختيارية مضمّنة مع APK وبدون تنفيذ ملفات محمّلة في مجلدات التطبيق، مراعاةً لقواعد W^X.
5. اختبارات تشغيلية على هواتف متعددة وإصدار إنتاجي موقّع.

الترخيص: Apache-2.0 للشيفرة الخاصة بالمشروع.
